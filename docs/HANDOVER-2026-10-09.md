## Traps

- **`xcodebuild -destination 'macOS'` is rejected** by this Xcode. Use
  `-platform=macOS`.
- **`script/shot.sh` opens the cockpit via AppleScript**, which only works because
  assistive access is now granted. Earlier in the project it was not.
- **Do not add a distributed-notification hook to open the cockpit.** One was built,
  launched, and never fired — `notifyutil -p` left `cockpitOpen` at 1 while an
  AppleScript click took it to 0. Removed rather than shipped. A door that silently
  does not open is the exact failure this project exists to avoid.
- **`script/shot.sh` trusts `SeaStar.cockpitOpen`**, which the app now writes `false`
  at launch. If that ever reverts, the script photographs the desktop instead of the app.
- **`majorsRingThePool` is a real guarantee**, not a nuisance: the majors' horizontal
  distance from centre is exactly the radius, so the roster is learnable. On a
  horizontal ring, z **is** a radial axis, so encoding the rung in z breaks it.
  Height is perpendicular to the ring and safe. Do not push nodes along z.
- **The founder's no-go zones** stand: his external drive and any mirror are off-limits.
- **Push, merge, and making the repo public** need his explicit word.
