### 4.5 The harness-config reader (D-021)

New: `src/sea_star/providers.py` (334 lines), `tests/test_providers.py` (15 tests).
Bridge: `providers[]` in `cli.py`. App: `ConfiguredProviderInfo` in `DoctorReport.swift`,
`declaredProvider(forHarnessNamed:)` in `ServerController.swift`, node subtitle and the
declared wire in `EntityGraphModel.swift`. 7 new Swift tests.

**Three findings from this that matter more than the feature:**

1. **The premise in four handoffs was stale.** They cite
   `~/.config/opencode/opencode.json` naming `"model": "atomic/Dirk-…"`. **That entry no
   longer exists.** The live file declares two MCP servers and no model at all.
2. **The first implementation consequently lied.** It accepted any URL and reported
   **`https://mcp.exa.ai/mcp` as OpenCode's model provider.** This is D-010's lesson
   repeating: *the presence of a URL is not the shape of a claim.* `_is_model_route`
   now admits only an inference surface (`/v1`, `/v2`, `/models`, `/completions`,
   `/embeddings`, or a bare loopback port) and rejects `/mcp` paths.
3. **On this machine the honest reading is empty.** No harness declares a model, so the
   panel says nothing. That is correct, not a failure — and it is exactly why the reader
   had to be built on evidence rather than on the handoff's remembered example.

The honesty rules: a declaration is **rung 0, never liveness**; derived fields only
(`provider`, `base_url`, `model` — a test asserts a config full of `apiKey`,
`authToken`, `password` yields a claim containing none of them); resolves to an endpoint
**only when Sea-Star can already see that endpoint answering**; a miss returns `nil`
rather than borrowing a neighbour's claim.

### 4.7 The 3D browser canvas, investigated (not built)

`docs/web-canvas-3d.md` (134 lines). Measured, not argued.

**It can be done.** `3d-force-graph` 1.80.1 is MIT, 6.4k stars: **364 KB gzipped**
against a 4.8 MB bundle (~7%), with orbit controls, click-to-focus, and a `dagMode`
layout that suits the cascade (the cascade *is* a DAG).

**Against it:** WebKit is a new framework dependency, not currently linked. The model
must be serialised to JSON across a `WKWebView` seam and crossed back. And its nodes are
**spheres** — the sea-star glyph is this app's identity.

**Why the record flip-flopped:** it was never about the technology. One decision slot
(spec **D3**) held two different questions. Embedding codebase-memory's *application* is
not feasible; embedding a *rendering library* is. Different answers.

**Recommendation: not yet.** The crowding complaint (thirteen ring points plus wires) is
a **layout-density** problem, not a rendering-power one, and thirteen nodes do not need
a force simulation. The **split panel** the founder raised in the same breath attacks
the actual complaint with none of those costs.

## 8. Traps a new session will otherwise walk into

- **`xcodebuild -destination 'macOS'` is rejected** by this Xcode. Use
  `-destination 'platform=macOS'`.
- **New Swift files need `xcodegen generate`** before they compile, or they are silently
  skipped. `CockpitTray.swift` is untracked *and* needs this.
- **The Metal toolchain is flaky.** `xcodebuild test` can fail with *"cannot execute
  tool 'metal'"* even when it is mounted. **Retry once** — it passed on the retry twice.
  `xcodebuild -downloadComponent MetalToolchain` if it persists.
- **Screen capture needs `-C`** to include the cursor, and the first attempt after
  launching can fail. Retry.
- **Assistive access is not granted to this host** (`osascript` returns −1719), and this
  model has no vision. Visual checks belong to the founder; measure via `defaults` and
  the window system instead. `SeaStar.cockpitOpen` is the readable flag.
- **`test` fails where `build` succeeds** from cache, because `test` recompiles
  `Shaders/Caustics.metal`.
- **`Fixture.report` keys are not overridable by `extraJSON`.** A duplicate
  `latent_harnesses` in injected JSON silently loses to the fixture's own. This cost one
  debugging round; `extraJSON` is for *new* keys only.
- **Never add an app name to a list to make something appear.** That is the trap the
  whole architecture exists to escape.
- **Changelog convention:** `Harness:` and `Date:` only. Never a model identifier — an
  agent cannot observe it, so the value would be invented.
- **The founder's no-go zones** (AGENTS.md): his external drive and any mirror of it are
  off-limits. Nothing is read, indexed or summarised from there. The `/Volumes` sweep was
  deliberately removed from `harnesses.py`.
- **Push/merge/publish need his explicit word**, always.
